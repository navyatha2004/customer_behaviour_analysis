1. Project Overview
This project demonstrates an end-to-end data analytics workflow using Python, SQL, and Power BI. The main objective is to transform raw data into meaningful insights through data cleaning, exploratory data analysis (EDA), SQL queries, and interactive dashboard development.

The project follows a practical data analyst workflow, from importing a dataset to presenting insights through reports and visualizations.

pip install pandas numpy matplotlib seaborn jupyter
